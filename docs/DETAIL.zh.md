# 雨海 · 高清视频皮肤

把窗口背景换成一段 Blender 渲染的 1080p 夜雨海面循环视频。视频是普通 H.264
文件，所以皮肤不需要 WebGL、不需要着色器，也几乎不占 GPU。

## 画面里有什么

- 夜雨下的开阔海面，右侧三分之一是一座亮着的浮标灯塔。
- 灯在湿海面上拉出断续的金色光带。
- 毫米级细雨丝，以及镜头附近少量虚焦水滴。
- 12 秒循环由 6 秒正向渲染 + 6 秒倒放拼成，首尾帧完全一致，没有可见接缝。

## 皮肤怎么工作

- Host 插件在 `/rain-ocean` 提供视频，支持 Range 请求，浏览器可以流式播放和循环。
- 浏览器模块在应用后面挂一个 `z-index: 0`、不接收鼠标的 iframe，并用 glass
  主题变量让外壳变成半透明。
- 侧栏底部、**设置**旁边的雨滴按钮打开皮肤面板。

## 操作

| 控件 | 作用 |
| --- | --- |
| 播放速度 | 录制为 24fps，可调 50–150% |
| 玻璃不透明度 | 覆盖在视频上的半透明外壳透明度，55–92% |
| 启用 | 移除或恢复视频，按钮始终保留 |
| 恢复默认 | 还原全部默认值 |

所有改动即时生效并保存在页面本地存储；面板底部会短暂提示「已保存」，并显示
视频规格。

## 视频规格

- 1920×1080、24 fps、H.264、12 秒无缝循环（6 秒正向 + 6 秒倒放）。
- Blender Cycles（RTX 5060 / OptiX）渲染，64 spp + OIDN。
- 视频在 `native-dist/rain-loop.mp4`（约 11MB），封面在 `native-dist/poster.jpg`。

## 限制

- 同一时间只应启用一个背景皮肤。
- 循环是 ping-pong 渲染：海浪在中点反向，这正是接缝不可见的原因。
